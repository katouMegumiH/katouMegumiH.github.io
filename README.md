# Zihan Li — Academic Homepage

Live website: https://katoumegumih.github.io/

This repository serves a static academic homepage from the root of the main branch through GitHub Pages.

## Editing

- index.html: biography, news, research interests, publications, journal metrics, and education.
- assets/academic/style.css: responsive layout and styles.
- assets/academic/favicon.svg: site icon.
- .nojekyll: serves the prebuilt static files directly.

The publication list includes three published papers and three manuscripts under review. CMPB and TFS are in second-round major revision; UniBioCLIP is under review at AAAI-27. The FEDformer paddy-quality paper is omitted at the author's request. Journal metrics are 2025 JIF values and quartiles from the 2026 JCR release, with source links on the homepage.

The previous Hexo homepage is preserved in branch codex/backup-before-academic-homepage-20260915. Existing posts, archive pages, and their CSS, JavaScript, fonts, and images remain at their original paths.
